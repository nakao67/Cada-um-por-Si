CADA UM POR SI — SITE + PAINEL ADMINISTRATIVO

O pacote está conectado à configuração web do Firebase do projeto cada-um-por-si-b5fca.

Arquivos:
- index.html: site público; a seção NOVIDADES carrega publicações do Realtime Database em tempo real.
- admin.html: painel administrativo separado para entrar com Google, publicar e apagar novidades.
- regras_firebase.json: regras do Realtime Database.

PRÓXIMOS PASSOS
1. No Firebase Console > Authentication > Sign-in method, confirme que Google está ativado.
2. Em Authentication > Settings > Authorized domains, adicione o domínio do GitHub Pages usado pelo site.
3. Em Realtime Database > Rules, publique o conteúdo de regras_firebase.json. A escrita fica limitada ao e-mail Nandomatheus28@gmail.com; a leitura pública permite que visitantes vejam as novidades.
4. Envie index.html e admin.html para a raiz do repositório GitHub Pages. O site público abre em / e o painel em /admin.html.
5. Faça login no painel com a conta Google Nandomatheus28@gmail.com.

O painel salva título, texto, link https opcional da imagem e data. O site público atualiza automaticamente quando houver novas publicações.

SEGURANÇA
A configuração web do Firebase é usada no navegador e não é uma senha. Nunca use regras que permitam escrita a qualquer pessoa. As regras do banco são a proteção real.
