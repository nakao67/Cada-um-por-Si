CADA UM POR SI — SITE + PAINEL ADMINISTRATIVO

Arquivos:
- index.html: site público com a página NOVIDADES.
- admin.html: painel separado para publicar e apagar novidades.
- regras_firebase.json: regras de segurança do Realtime Database.

IMPORTANTE: os arquivos ainda NÃO estão conectados ao seu Firebase e não estão publicados. Para funcionar online, faça a configuração abaixo.

1. No Firebase Console, abra seu projeto e adicione um app Web (ícone </>). Copie a configuração do SDK.
2. Cole os mesmos valores no objeto firebaseConfig dentro de index.html e admin.html. Ajuste databaseURL para a URL exata exibida no console do Realtime Database.
3. Em Authentication > Sign-in method, ative Google.
4. Em Realtime Database, crie o banco e publique as regras de regras_firebase.json, trocando SEU_EMAIL_GOOGLE_AQUI pelo seu e-mail Google. Use o mesmo e-mail na constante ADMIN_EMAIL de admin.html.
5. Em Authentication > Settings > Authorized domains, adicione o domínio do seu site GitHub Pages quando já existir.
6. Publique index.html e admin.html no repositório GitHub Pages. O endereço público será o endereço do repositório; o painel fica em /admin.html.

SEGURANÇA: não publique nem compartilhe o painel como segredo de segurança; a proteção real é feita pelas regras do Firebase. Não deixe as regras como leitura/escrita liberadas para todos. A configuração web do Firebase pode aparecer no site, mas as regras devem limitar escrita ao seu e-mail.

O painel publica novidades com título, texto e link https da imagem. A página pública atualiza automaticamente quando há novas publicações.
