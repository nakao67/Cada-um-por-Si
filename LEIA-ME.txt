IMPORTANTE: para fotos da galeria, ative o Firebase Storage no projeto Firebase e configure regras para que somente o administrador autenticado possa enviar/apagar arquivos e visitantes possam ler as imagens. Se o Storage não estiver ativado, publicações sem upload por link continuam disponíveis.

O arquivo regras_firebase.json incluído contém regras completas do Realtime Database para /posts e /siteContent: visitantes podem ler; somente nandomatheus28@gmail.com pode escrever. Se for substituir as regras, confira se nenhum outro recurso importante do seu banco depende de regras adicionais.


Regras do Firebase Storage (cole em Firebase Console > Storage > Rules depois de ativar o Storage):

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null && request.auth.token.email == 'nandomatheus28@gmail.com' && request.resource != null && request.resource.size < 8 * 1024 * 1024 && request.resource.contentType.matches('image/.*');
    }
  }
}

A regra permite visitantes verem as imagens e só a conta administradora enviar imagens de até 8 MB.
